kirinuki

This app uses YouTube API Services.

kirinuki is a personal, non-commercial tool used only by the owner of the YouTube channel holo-jp-clips to upload videos that the owner has edited (English-subtitled clips) to that channel.

What it does

  • Uploads a finished video file from the owner's computer to the owner's own YouTube channel (videos.insert).
  • Sets the video's title, description, tags, category, language and "made for kids" setting.
  • Sets the video's custom thumbnail (thumbnails.set).
  • Reads back the status of the uploaded video (videos.list) and the owner's channel name (channels.list).

It runs only on the owner's own computer as a command-line tool, has no server and no other users, and is not distributed or sold.
