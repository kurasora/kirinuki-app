Privacy Policy

Last updated: October 30, 2026

kirinuki ("the app") is a personal tool used only by the owner of the YouTube channel holo-jp-clips to upload the owner's own videos to that channel.

YouTube API Services

The app uses YouTube API Services. By using the app, users agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy (https://policies.google.com/privacy).

Information the app accesses, uses and stores

With the user's permission (Google OAuth 2.0), the app uses the YouTube Data API to:

  • upload video files that the user selects on the user's own computer to the user's YouTube channel;
  • set each video's title, description, tags, category, language, "made for kids" setting and thumbnail;
  • read back the status of those videos and the name and ID of the user's channel.

The only data stored is the OAuth access/refresh token, which is kept in a local file on the user's own computer. The video IDs and URLs of uploaded videos are recorded in local project files on the same computer. The app has no server. It does not collect, sell, share or transfer any data to anyone, and it does not use any cookies or tracking. It does not access any other user's data.

Revoking access and deleting data

The user can revoke the app's access to their Google account at any time via the Google security settings page: https://myaccount.google.com/permissions.

Deleting the local token file (secrets/youtube_token.json) immediately deletes all stored authorization data. API data obtained by the app is not kept beyond what is described above; if access is revoked, the app no longer accesses any data, and any locally stored token is deleted within 7 days.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
