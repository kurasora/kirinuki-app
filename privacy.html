Privacy Policy

Last updated: October 30, 2026

kirinuki is a personal tool used only by the owner of the YouTube channel holo-jp-clips to upload the owner's own videos to that channel.

Data the tool accesses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos to the owner's channel, set each video's title, description, tags, category, language and thumbnail, and read back the status of those videos.

How data is stored

The OAuth token is stored only on the owner's own computer. The tool has no server, and it does not collect, sell or share any data with anyone. It does not access any other user's data.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy and the YouTube Terms of Service (Google Privacy Policy).

Contact

Please contact the owner through the holo-jp-clips YouTube channel.
